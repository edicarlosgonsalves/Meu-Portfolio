# Portfólio — Edicarlos Gonsalves

Portfólio responsivo de desenvolvedor web, feito com HTML, CSS e JavaScript puro, com tema preto e verde neon.

## Arquivos

- `index.html` — conteúdo e seções do portfólio
- `style.css` — visual, responsividade e animações
- `script.js` — menu mobile, ano do rodapé e botão de copiar e-mail

## Antes de publicar

1. Revise o texto da apresentação e das habilidades para refletir com precisão teu nível atual.
2. Em `script.js`, preencha a variável `emailContato` com teu e-mail profissional (ou remova o botão de e-mail se preferir não divulgar).
3. Em `index.html`, atualize o link `nikeCodeLink` para o repositório real do projeto Nike. Não deixe links de exemplo.
4. Troque os cards de projetos planejados por projetos reais quando estiverem prontos.
5. Teste em computador e celular.

## Testar localmente

Abra `index.html` no navegador ou use a extensão Live Server do VS Code.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `portfolio`.
2. Envie `index.html`, `style.css`, `script.js` e este README para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação e abra a URL mostrada pelo GitHub Pages.

Este portfólio é estático. O GitHub Pages não executa Node.js, não hospeda APIs privadas e não processa pagamentos. Para projetos com back-end, publique o front-end e o servidor em serviços apropriados e mantenha chaves secretas apenas no servidor.
